# Wwise SoundBanks for First Dive

Drop Wwise-generated banks here after generating for the **Web / Emscripten** platform.

Expected (names may match your Wwise project):
- `Init.bnk`
- `Dive.bnk` (or your main bank)
- any `.wem` / streamed media the banks reference
- the Wwise Web runtime (`AkSoundEngine.js` / `.wasm` / AudioWorklet files) from your SDK install

Do not commit licensed SDK binaries unless the project already has redistribution rights.
